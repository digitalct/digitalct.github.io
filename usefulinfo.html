Useful links

Spintronics and Magnetic Materials

1. Micromagnetic & Magnetics Simulation Software

Mumax3 (GPU-Accelerated Micromagnetics)
High-performance GPU-based micromagnetic simulation software widely used to model domain wall dynamics, skyrmions, and spin waves.
https://mumax.github.io →
OOMMF (Object Oriented MicroMagnetic Framework)
The NIST standard framework for 2D/3D micromagnetic calculations and domain structure predictions.
https://math.nist.gov/oommf/ →
Vampire (Atomistic Spin Dynamics)
Atomistic simulation package for modeling magnetic materials at finite temperatures, ideal for Curie temperature calculations and exchange coupling.
https://vampire.york.ac.uk →

2. Open Crystallographic & Material Databases

Crystallography Open Database (COD)
An open-access collection of crystal structures (CIF files) essential for setting up XRD phase identification and atomic models.
http://www.crystallography.net/cod/ →
The Materials Project
An open database providing calculated electronic, magnetic, and crystal properties for thousands of inorganic compounds.
https://materialsproject.org →

3. Society Journals & Preprint Repositories

arXiv (Condensed Matter)
Free repository for preprints in experimental spintronics, magnetism, and condensed matter physics.
https://arxiv.org/archive/cond-mat →
IEEE Magnetics Society
Access point for conference proceedings (INTERMAG, MMM) and publications covering experimental magnetism and spintronic devices.
https://ieeemagnetics.org →
AIP Journal of Applied Physics / APL
Leading journals publishing experimental setups, MOKE magnetometry, AFM/MFM studies, and spin-torque measurements.
https://pubs.aip.org →

4. Open Analysis & Data Processing Tools

Gwyddion
Free, open-source modular program for SPM (AFM, MFM, STM) data visualization and quantitative profile analysis.
http://gwyddion.net →
FullProf Suite
X-ray and neutron diffraction profile analysis suite for Rietveld refinement of magnetic crystal structures.
https://www.ill.eu/sites/fullprof/ →
